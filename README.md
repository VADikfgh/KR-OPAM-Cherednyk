# KR OPAM Cherednyk - AutoDealer CRM

Система управління автосалоном (WinForms, C#, MySQL).

## Інструкція з розгортання:
1. Клонуйте репозиторій на свій комп'ютер.
2. Імпортуйте файл бази даних **`autodealer_db.sql`** у ваш локальний сервер MySQL (через phpMyAdmin або інший клієнт).
3. Перевірте та за потреби змініть рядок підключення до бази даних (Connection String) у файлі конфігурації проєкту.
4. Відкрийте файл рішення (`.sln`) у Visual Studio та запустіть проєкт.
